# SharedBridge — Empyrion Scenario Fixer Group Only

This folder is the handoff point **only** for the Empyrion Scenario Fixer and Scenario Fixer's Assistant bots working on the local Ascension-Reborn scenario (F:\SteamLibrary\...\Ascension-Reborn) and related Empyrion tooling.

**Do not use this for Stellar Unity bots.** Those have their own bridge in the Tevishtszaat/Stellar repo.

Note: Scenario Fixer's Assistant normally avoids GitHub pushes. Bridge status/thoughts files are an explicit exception so Grok can see progress. Prefer short notes; large data can stay local or go in data/.

- Grok can read/write these files via GitHub.
- Empyrion bots can pull, append notes, and push bridge updates only.
